⚠ Content filter is blocking secure connections

A network security tool (Zscaler, Netskope, GlobalProtect, or similar) is intercepting HTTPS traffic. This prevents VS Code extensions, AI connections, and software downloads from working.

  1. Find the security app in your menu bar or system tray
  2. Choose Disable or Pause and pick the longest time option
  3. This page will update automatically when the connection is restored
  4. Re-enable the security tool when you are done installing or downloading
