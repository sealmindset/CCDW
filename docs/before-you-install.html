Before You Install — Claude Code

Make sure these items are ready before running the installer. Most take 5 minutes or less.

Checklist progress 0 of 0
Required for everyone

Essentials

These apply no matter which AI provider you use.

Docker is installed
You need Docker Desktop or Rancher Desktop (both are free).
  • macOS Download from docker.com or rancherdesktop.io
  • Windows Download Rancher Desktop — no admin password needed
Docker is running
Open it from your Applications folder macOS or Start menu Windows and wait for it to finish loading.
Internet connection
Make sure you can browse the web normally. The installer downloads about 1 GB on the first run.
5 GB free disk space
The Docker image and container data need room to work.
If applicable

If Your Company Uses a Content Filter

Zscaler, Netskope, GlobalProtect, or similar tools can block Docker image downloads.

Pause the content filter before installing
  • Look for Zscaler, Netskope, or GlobalProtect in your menu bar macOS or system tray Windows
  • Choose Pause or Disable and pick the longest time option
  • You can re-enable it after the install finishes
Who to contact: Your IT help desk can temporarily disable the content filter if you cannot pause it yourself.
Provider-specific

For Azure AI Foundry Users

Choose this if your organization uses Claude through Microsoft Azure.

Azure subscription access
You need access to the AI Foundry Azure subscription used by your team.
Who to contact: Your manager or the AI CoE team can request subscription access for you.
VPN connected (or on corporate network)
Connect to GlobalProtect or your company VPN. The AI Foundry endpoint must be reachable from your machine.
Azure CLI installed (optional)
The Azure CLI is included inside the container, but having it on your host machine helps for pre-checks. Download from microsoft.com.
Provider-specific

For AWS Bedrock Users

Choose this if your organization uses Claude through Amazon Web Services.

AWS SSO access
You need permission to use Bedrock models through your AWS SSO account.
Who to contact: Your manager can request access through your company's access portal (e.g., Okta group for Bedrock model access).
AWS SSO URL and account details
You will need your SSO start URL, AWS account ID, and SSO role name. Get these from your team lead.
AWS CLI v2 installed
Required for SSO authentication. Download from aws.amazon.com.
Provider-specific

For Anthropic API Key Users

The simplest option — no VPN or corporate access needed.

API key ready
Get your key from console.anthropic.com. It starts with sk-ant-. Keep it somewhere safe — you will paste it during install.
Windows only

Windows-Specific Steps

Skip this section if you are on macOS.

WSL2 installed
Open PowerShell and run: wsl --install, then restart your computer. Rancher Desktop needs WSL2 to run containers.
Do NOT run the installer as Administrator
Just double-click install.bat normally. Running as Administrator causes files to end up in the wrong user folder.

Once everything above is checked off, double-click the installer file to get started.

The install takes about 2 – 3 minutes on a good connection.

Need help? Contact your IT help desk or the AI CoE team in your organization.
